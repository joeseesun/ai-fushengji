# 单屏与下一步引导改版

2026-10-28，用户反馈：“一个页面呈现完整内容”“不知道下一步干啥”“不要上下左右滑动才能看清楚”。保留已选定的 A「千禧年打工桌面」，调整信息结构和操作引导。

## 原始问题与依据

真实浏览器在 1365×768 视口测得旧版游戏页面高 1853px。事件锁定其他操作，但行动和换站在页面下方；玩家不能同时看到阻塞原因与下一步。此前的“无横向溢出”验收不足以证明单屏可玩。

- [NN/g：Recognition and Recall](https://www.nngroup.com/articles/recognition-and-recall/)：将当前操作与上下文提示放在界面里，降低玩家记忆教程的负担。因此保留常驻目标、当前待办，以及操作后的阶段提示。
- [Game Accessibility Guidelines：Interactive Tutorials](https://gameaccessibilityguidelines.com/include-interactive-tutorials/)：在实际游玩中教授机制，比单独的说明屏更容易建立操作与规则的联系。因此第一天直接让玩家完成“回应事件、做两次行动、过夜”，不加阻塞式导览。
- [NN/g：Progressive Disclosure](https://www.nngroup.com/articles/progressive-disclosure/)：主要功能优先展示，低频资料用明确入口访问。图鉴、模型大全、档案和规则使用带标题的阅读窗口，所有内容都保留。

这些原则指导本次实现，不代表单屏或翻页是所有游戏的通用最佳方案。此处选择它们，是为满足用户明确的零滚动约束。

## 具体交互

- 主窗口使用视口高度。桌面同时显示事件、八项行情、六种行动；每日目标、现金、欠款、健康、压力和结束今天按钮常驻。
- 固定流程：① 处理事件 → ② 自选两次行动 → ③ 选站并结束今天。回应事件后，窄屏自动切到行动；行动完成后提示结束今天。交易、还款仍可自由安排，不强制照建议操作。
- 下一站通过选择框确定，结束今天用独立按钮执行。站点特点和费用在执行前可查；剩余行动未用完仍须确认。
- 窄屏使用事件 / 交易所 / 行动三个按钮切换同一窗口。长内容按完整段落、选项或卡片分页，提供上一页、下一页和页码。无需滑动，也不缩小正文或省略风险结果。
- 在低高度横屏中进一步收紧装饰和导航，保留阅读区与主操作。梗图、模型、账本、规则也采用分页。
- 保留全部事件、模型、GPU、经济规则和存档格式；不新增真实模型调用。

## 验证

在桌面及手机浏览器视口完整操作 40 天，测试自动存档、刷新、交易、模型、导入、离线与结局卡。布局回归另检查 1365×768、1440×900、1024×768、390×844、320×568、844×390、683×384：页面尺寸不超过视口，主操作在屏内，每个事件选项均能通过按钮到达，分页块不覆盖分页控制。

额外用全部 80 个日常事件与 5 个阶段事件执行边界扫描，发现并修复小屏与横屏的滑块高度问题。浏览器视口检查不等于实际手机硬件测试，真人上手体验仍以继续试玩为准。
