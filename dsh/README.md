# AI 浮生记 · DSH 游戏商店版

背着 8,000 元培训贷开局。你有 40 天倒腾算力、接零工、做项目，最后还清欠款，保住健康。

在 DeepSeek Harness 里安装 `dsh-game-store`，从「我的游戏」打开 AI 浮生记。也可将发布包安装到已有 Web profile：

```sh
dsh plugin --profile web add ./dsh-game-ai-fushengji-0.11.1.tgz
```

商店版为简体中文单人游戏。自动存档与排行保存在当前游戏环境。要在商店与原网站之间转移一局，使用「存档」里的 JSON 文本复制或粘贴。

[完整源码与构建说明](https://github.com/joeseesun/ai-fushengji) · [独立网页版](https://fusheng.qiaomu.ai/) · [MIT](LICENSE)

**AI Life Simulator** is a Chinese-language single-player game. Pay off your debt in 40 days by trading, taking gigs and managing your health. Install the package in a DSH profile that has `dsh-game-store`, then open it from My Games. The store edition saves progress and scores locally and supports copying or pasting save JSON.
